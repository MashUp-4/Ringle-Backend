# 문제 정의서

## 1. 문제 정의 표

| 항목 | 내용 |
| --- | --- |
| 대상 사용자 | [영어회화를 위해 나에게 맞는 튜터를 선정하려는 사용자] |
| 문제 상황 | [튜터를 선택하는 과정이 너무 길다] |
| 핵심 불편과 원인 | [튜터 탭의 현재 문제는 튜터의 후기 수, 평균 평점, 주요 강점 키워드가 튜터 선택 화면에 즉시 노출되지 않고, 튜터별 상세페이지 (프로필 보기)의 ”수업 평가“ 탭으로 매번 들어가는 탐색 과정을 거쳐야 한다.] |
| 영향 | [튜터 선택 시 비교와 판단에 시간이 오래 걸려 핵심 행동: “튜터를 결정하기” 과정으로 가는데에 피로감을 느낀다.] |
| 해결 방향 | [튜터 선택 페이지에서 즉시 [평점/리뷰 수 + 튜터별 강점 키워드]를 보여준다.] |
| 기대 효과 | [튜터를 선택하고 있는 사용자가 자신에게 맞는 튜터를 적은 탐색 시간을 투자하여 직관적으로 알 수 있게 하여 사용자가 튜터를 선정하는 과정에서 화면 이동을 줄여 피로감을 줄인다.  |

## 2. 문제 한 문장

> [영어회화를 위해 나에게 맞는 튜터를 선정하려는 사용자]는 [튜터를 선택하는 화면]에서 [튜터별 특징이 직관적이지 않아서 ]  [튜터 결정을 하는데에 피로감을 느낀다.].
> 

수정_민서 

(1)

| 항목 | 내용 |
| --- | --- |
| 대상 사용자 | [나에게 맞는 최적의 영어 회화 튜터를 효율적으로 탐색 및 비교하고 싶은 학습자] |
| 문제 상황 | [튜터 탐색 과정(추천·전체·찜 목록 등)에서 튜터를 탐색하고 비교 선택할 때] |
| 핵심 불편과 원인 | [튜터의 핵심 정보(평점/리뷰 수, 수락률, 주요 강점)가 메인 탐색 카드 영역에 즉시 제공되지 않고, 추천·필터·찜 영역 간 이동 및 튜터 검색 과정에서 과도한 화면 진입이 발생한다.] |
| 영향 | [튜터 선택 시 비교와 판단에 시간이 오래 걸려 핵심 행동: "튜터를 결정하기" 과정으로 가는데 피로감을 느낀다.] |
| 해결 방향 | [모든 탐색 과정(추천/전체/찜한 튜터 목록)에서 프로필 카드 직관화(평점·수락률·호버 정보 제공) 및 고정 필터·찜하기 바로가기 UX를 구현한다.] |
| 기대 효과 | [학습자가 튜터 탐색 전 과정에서 이탈 없이 빠르게 자신에게 맞는 튜터를 비교·선정할 수 있어 결정 시간을 단축하고 UX 피로도를 최소화한다.] |

(2)

[영어회화를 위해 나에게 맞는 튜터를 선정하려는 사용자]는 [튜터 탐색 전 과정(추천·전체·찜)에서 튜터별 핵심 정보가 직관적이지 않고 탐색 효율이 낮아] [튜터 결정 및 예약까지의 과정에서 피로감을 느낀다.]

## 예시

| 항목 | 내용   |
| --- | --- |
| 대상 사용자 | 평일 밤 혼자 한 끼를 시키려고 배달 앱을 켠 자취생 |
| 문제 상황 | 메뉴 하나를 담고 장바구니에서 "주문하기"를 눌렀을 때 그제야 최소 주문 금액 미달 안내를 본다 |
| 핵심 불편과 원인 | 최소 주문 금액이 가게 상세 상단에 작은 글씨로만 있고, 장바구니에는 얼마가 부족한지 나오지 않는다. 팀원 5명 중 4명이 메뉴 목록으로 되돌아갔다 |
| 영향 | 사용자는 메뉴 목록과 장바구니를 두세 번 오가고, 5명 중 1명은 주문을 포기하고 다른 가게로 갔다 |
| 해결 방향 | 장바구니에서 부족한 금액을 바로 보여주고, 그 자리에서 채울 수 있게 한다 |
| 기대 효과 | 장바구니에서 되돌아가는 횟수 감소, 주문 완료까지 화면 이동 수 감소 |
